# Econ_note2pdf

将高级经济学课程的板书照片和手写笔记 PDF 整理为可直接阅读、复习的 LaTeX 讲义与 PDF。

## 项目状态

首版开发中：P1 规格与数据契约已完成，转换工具尚未实现。

## 开发入口

- Codex 先阅读 [AGENTS.md](AGENTS.md)。
- 按 [v0.1 开发计划](docs/plans/2026-10-31-v0.1-development-plan.md) 的五个阶段实施并记录进度。
- 使用任务分支和草稿 PR 交付阶段变更，区分开发完成、自检完成和真实材料验收。

## 产品方向

- 优先处理板书照片，同时支持手写笔记 PDF。
- 面向宏观、微观、计量与经济数理，覆盖公式、推导、图与表格。
- 在 Codex、Claude Code 等 agent 宿主中使用宿主模型完成识别与整理。
- 支持忠实转录、复习讲义或两种版本；交付 PDF 和可编辑 LaTeX 工程。
- 正文强调逻辑、完整性与可读性；一般复核事项放入附录，技术日志保留在工程目录。

真实材料测试与用户验收在首版开发完成后安排。
